## 3. How sms-activate review findings work

The **sms-activate review** focuses on three parts of the activation process:

1. Whether a number can actually be issued.
2. Whether the verification SMS arrives.
3. How long the code takes to arrive.

The process starts by selecting a service and country. If a number is available, the user purchases it and enters the number into the relevant service. Incoming SMS messages are then displayed in the SMS-MAN interface.

A key issue is the difference between **catalog availability and live availability**. A country may appear to have numbers available while an attempted purchase returns `NO_NUMBERS`.

When an SMS does not arrive, another number may be required. This means the actual time and cost of completing a verification can be higher than the initial activation price suggests.
